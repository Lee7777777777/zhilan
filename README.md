# 知览 · 本地知识库

把 `.md` 知识点文件导入后完美渲染成阅读页面，而不是显示 Markdown 源码。

## 运行

双击 `启动知览.bat`（推荐）：会自动检测 Python、缺依赖时自动 `pip install -r requirements.txt`，然后以无控制台窗口方式启动。

调试模式（带 DevTools 与控制台输出）：

```bash
"启动知览.bat" --debug
# 或
python main.py --debug
```

导入方式：点击左侧「＋ 导入知识点」，或把 `.md` 文件直接拖进窗口。导入完成会在底部提示收录了几个文件。

## 右键打开 .md

在资源管理器里右键任意 `.md` 文件 → 「用知览打开」（Windows 11 需要点「显示更多选项」或按 `Shift+F10`），文件会自动收进知识库并直接打开。

- 菜单项只写当前用户注册表（`HKCU\Software\Classes\SystemFileAssociations\.md\shell\ZhiLan`），不需要管理员，也不会改动 `.md` 的默认打开方式。
- 注册：`python tools/shell_menu.py register`；查看：`status`；取消：`unregister`。换了 exe 位置后用 `--exe` 指定新路径重新注册。
- 同一文件重复打开不会产生重复条目，仍是更新原条目，分类归属不变。
- **单实例**：知览已经开着时，新文件会交给已有窗口处理并自动打开，不会起第二个进程抢着写同一个库。程序会在 exe 同级写一个 `.instance.json` 记录端口，下次启动据此判断是否已有实例；正常退出时自动清掉，被强杀留下的残留会自动识别并清理。

## 新建知识点

点「新建」直接创建一篇空白知识点（存在库内，没有外部文件），随即进入编辑状态，写完 `Ctrl+S` 保存。

- 新建的知识点没有原件，正文就是 `library/items/<id>.md`；「定位文件」会选中该副本。
- 「同时重命名磁盘上的 .md 文件」对这类条目不可用（没有外部文件可改），会给出提示。
- 若要在库里写图文笔记，把图片放进 `library/assets/<id>/`，正文用相对路径引用即可。

## 分类与文件管理

- 左侧「＋ 分类」新建分组；分组条上点 ✎ 重命名、点 ✕ 两次删除（删除只删分组，知识点退回未分类）。
- 点分组标签筛选；「全部 / 未分类」始终存在。选中某分组后，导入与拖进来的文件自动归入该分组。
- 阅读页右上角的下拉框可把当前知识点移动到别的分类。
- 「定位文件」在资源管理器中选中原始 .md；「移除」只从知识库删除，不碰原文件。
- 重复导入同一个文件（同名同目录）会更新原条目而不是新增，分类归属保持不变。

## 自定义显示名

知识点默认用文件里的标题（YAML `title` > 首个 `#` 标题 > 文件名）。想换个叫法：

- 点阅读页右上角「重命名」，或在左侧条目上右键选「重命名显示名」，输入后回车保存。
- 只改知识库里显示的名字，**不会动 .md 文件内容**；正文的一级标题仍是原样。
- 勾选「同时重命名磁盘上的 .md 文件」才会真正改名文件（同名冲突、非法字符会被拒绝并提示）。
- 「用回原标题」清除自定义名；自定义名会出现在侧栏、窗口标题和搜索结果中，
  重导入同一文件时保留。

## 右键菜单与原文编辑

在左侧知识点上点右键：**打开阅读 / 查看 · 编辑原文 / 重命名显示名 / 在文件夹中定位 / 从知识库移除**。

- 「查看 · 编辑原文」在正文区打开该知识点的 Markdown 源文件，改完 `Ctrl+S` 保存，`Esc` 关闭；
  有未保存修改时需再点一次才会放弃。
- 保存写回的是**原始文件本身**（原件丢失时写库内副本），覆盖前自动把旧版本存到
  `library/backups/`，并同步库内副本、刷新标题与标签。
- 阅读页顶部的文件名也可点击，同样进入原文编辑。
- 编辑器内 `Tab` 插入四个空格，不跳出输入框。

## 外观设置

点击左上角齿轮（或按 `Ctrl+,`）打开设置面板，可实时调整并自动保存到 `library/settings.json`：

| 项目 | 可选值 |
|---|---|
| 配色模式 | 深色 / 浅色 / 护眼（米黄） |
| 强调色 | 8 个预设 + 自定义取色器 |
| 阅读字体 | 无衬线 / 衬线 / 等宽 |
| 字号 | 13–22 px |
| 行高 | 1.4–2.2 |
| 正文宽度 | 620–1200 px |
| 侧栏宽度 | 220–400 px |
| 间距 | 宽松 / 紧凑 |
| 代码配色 | 深色块 / 浅色块 |
| 右侧目录 | 显示 / 隐藏 |

左下角按钮可快速循环三种配色模式。快捷键：`Ctrl+,` 设置、`Ctrl+F` 搜索、`Ctrl+O` 导入、`Ctrl+S` 保存原文、`Esc` 关闭面板或编辑器。

设置面板底部的「清理孤儿备份与图片」可删除已移除知识点留下的备份、正文副本与图片副本（现存知识点的历史备份一律保留）；按钮下方会显示可清理的文件数与占用空间，点两次确认才执行。

## 能力

- 表格、任务列表、删除线、脚注、`!!! note` 提示块
- 代码高亮（highlight.js）、LaTeX 公式（KaTeX，行内 `$...$` 与块级 `$$...$$`）
- Mermaid 流程图 / 时序图（按需加载：只有正文含图表时才读取 `mermaid.min.js`，因此首次打开这类笔记会稍慢一拍）
- 相对路径引用的本地图片自动可读，**导入或保存时会把图片一并复制进 `library/assets/`**，因此整个 `library` 文件夹搬走也不会丢图
- 非 UTF-8 的 `.md`（GBK、带 BOM 等）自动识别并转存为 UTF-8，正文与标题不会乱码
- 标题与 `#标签` 自动识别（优先 YAML front matter，其次首个 `#` 标题，最后文件名）
- 右侧目录随滚动高亮，点击跳转；左侧支持标题与标签搜索，命中处高亮
- 全部前端资源离线打包在 `assets/web/`，断网可用

## 数据位置

| 路径 | 内容 |
|---|---|
| `library/index.json` | 知识点索引与分类定义 |
| `library/items/` | 导入时复制进来的 Markdown 正文（统一为 UTF-8） |
| `library/assets/<id>/` | 正文引用的本地图片副本，按条目分开存放 |
| `library/settings.json` | 外观设置（不存在时用默认值） |
| `library/backups/` | 编辑原文保存前的自动备份（按知识点 id + 时间命名） |
| `.instance.json` | 运行中的实例端口，用于单实例判断与文件转发；正常退出时自动删除 |
| `sample/` | 两个可直接导入的示例文件 |

「移除」只从知识库删除，不动原始文件；条目对应的 `items/` 正文、`assets/` 图片副本会一并清除（原件仍在原目录）。

## 打包成单个 exe

```bash
build_exe.bat            # 或 python -m PyInstaller --noconfirm --clean zhilan.spec
```

产物是 `dist\知览.exe`（约 17 MB，单文件，免安装 Python），复制到项目根目录即为日常使用的 `知览.exe`。

运行时会解压到临时目录，因此**用户数据固定放在 exe 同级的 `library\` 文件夹**：

- exe 在项目根目录 → 直接使用现有知识库（当前就是这种状态）。
- 拷到桌面或其他目录 → exe 旁边会自动新建空的 `library\`；想带走数据，把整个 `library` 文件夹一起复制过去即可（图片已随库保存，不会丢）。
- 换了位置之后，右键菜单里写死的还是旧路径，需要用 `python tools/shell_menu.py register --exe "新路径\知览.exe"` 重新注册。

`build\` 和 `dist\` 都是打包中间产物，可以随时删除，下次打包会重新生成。首次启动比源码运行慢 2–4 秒属正常（单文件模式需解压）。窗口异常时会在 exe 同级生成 `知览-崩溃日志.txt`。

## 结构

```
启动知览.bat        双击启动源码版（含 Python 与依赖自检）
build_exe.bat       一键打包成单文件 exe
zhilan.spec         PyInstaller 配置（资源打包、隐藏导入、排除 Qt）
知览.exe            日常使用的单文件程序（数据在同级 library\）
main.py            桌面窗口外壳（pywebview + WebView2）、命令行参数与单实例
app/paths.py       资源目录与数据目录分离（源码 / 打包两种运行方式）
app/server.py      本地 HTTP 服务：静态资源、知识点、外观设置、存储清理、
                   外部打开（长轮询推送）与单实例探测接口
app/renderer.py    Markdown -> HTML（含公式保护、锚点与目录提取、图片引用解析）
app/kb_index.py    索引与文件存储（原子写入、图片副本、孤儿清理）
app/ui/            界面 HTML / CSS / JS
assets/web/        KaTeX、Mermaid、highlight.js 离线资源
assets/icon/       图标（app.ico 与源图、各尺寸预览）
dev_server.py      仅起服务，便于在浏览器里调试渲染效果
tools/             make_icon.py 生成多尺寸 ico；draw_icon.py 画图标源图；
                   shell_menu.py 注册 / 注销 .md 右键菜单；
                   capture_window.py 抓窗口画面（WebView2 内容抓不到，只能截到外框）
sample/            两个可直接导入的示例 .md
library/           知识库数据（索引、正文、图片副本、备份、设置）
```

两个 .bat 文件的内容必须保持纯 ASCII：cmd 以 OEM 代码页解析批处理，中文注释会破坏 `rem` 行。
